Como funciona

O PesaBoi já possui um gateway no servidor que encaminha as solicitações para os fornecedores. Preencha aqui apenas as credenciais que você já obteve. O botão gera um arquivo central-agro.env no seu computador; depois, importe-o uma única vez em Render → Environment → Add from .env.

Não existe uma chave universal que substitua as contas do Google, Embrapa e Hugging Face. Este assistente reúne as chaves necessárias num único arquivo. Os valores digitados não são enviados ao PesaBoi, não são salvos no navegador e não são enviados ao GitHub por esta tela.

ÚLTIMA ETAPA

Importar no Render uma única vez

  1. Baixe o arquivo gerado central-agro.env.
  2. Abra o serviço PesaBoi no Render Dashboard.
  3. Entre em Environment e clique em Add from .env.
  4. Selecione central-agro.env e salve com Save, rebuild, and deploy (ou a opção equivalente exibida).
  5. Quando o deploy terminar, volte aqui e clique em Atualizar status.

O arquivo contém chaves em texto legível. Guarde-o em local privado, não o envie por e-mail/mensagens, não o coloque no GitHub e apague a cópia depois de importar. Não compartilhe o arquivo .env com ninguém.

VISÃO COMPUTACIONAL AGRÍCOLA

Triagem de pragas e doenças por fotografia

Fotografe a praga ou o dano na planta. O módulo usa o detector de insetos IP102 pela Hugging Face quando um endpoint dedicado está configurado; TensorFlow.js pode executar um modelo local compatível.

Configure HF_TOKEN e HF_PEST_ENDPOINT_URL no Render. O modelo IP102 não está implantado em um Inference Provider compartilhado. TensorFlow.js local requer modelo TF.js de pragas em /models/pest-detection/.
Aguardando imagem.

O detector IP102 reconhece apenas as classes presentes no conjunto de treinamento; fotos brasileiras e condições reais podem diferir. Respostas de confiança baixa ou formato desconhecido são inconclusivas. Confirme com agrônomo e não aplique defensivo apenas com base no classificador.
